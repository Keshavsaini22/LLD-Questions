File Management System- Design a system similar to a basic computer file explorer.
A user should be able to organize files and folders in a hierarchy.

Think of a file explorer on your computer.

Its primary responsibility is organizing and managing files and folders.

- Create, delete, rename, and move files/folders.
- Navigate a folder hierarchy.
- Search and list files.
- Manage folder relationships and metadata.
  Typical LLD focus: objects, hierarchy, operations, and design patterns.




Functional requirements
- Create files and folders.
- List folder contents.
- Search by name and retrieve a path.
- Rename, move, and delete items.
- Calculate file and recursive folder sizes.
- Prevent duplicate names within the same folder.
- Support nested folders.
