Cloud File Storage System (Google Drive-like)

Think of storing and accessing files through the cloud, across devices and users.

It includes file management, but also has to manage the actual file content and access to it.
- Upload and download file content.
- Store large files and track their metadata.
- Share files and folders with other users.
- Enforce permissions.
- Handle versions, concurrent edits, and concurrent uploads.
- Support synchronization and recovery.
Typical LLD focus: file metadata, content storage, access control, versioning, and concurrency.
